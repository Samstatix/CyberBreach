# CYRO logo asset

Place the exact user-approved CYRO logo image at:

`apps/web/public/cyro-logo.png`

Vite serves this file at `/cyro-logo.png`. The CYRO assistant header is already wired to this path and gracefully falls back to its icon if the image is absent.

Do not redraw, regenerate, recolor, crop, or substitute the approved logo. Preserve the supplied artwork. The PNG binary must be added through a binary-capable Git upload; the text-only repository file action cannot preserve the original image bytes.
